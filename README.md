# Darsid Studio

**Darsid Studio** is an independent animation studio founded and owned by **Yitoke Lone**. The studio focuses on developing original animated projects, characters, and creative media.

Darsid Studio operates independently and is based around the development of original animation projects. Its work includes 3D animation, storytelling, character development, and related creative production.

The studio developed from an earlier community and creative project known as **Wolf Den**, before adopting the Darsid identity in 2026.
