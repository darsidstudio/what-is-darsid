# Darsid Studio

Darsid Studio is an independent animation project in development, building toward original animated productions and creative media.
The studio developed from an earlier community and creative project known as **Wolf Den**, before adopting the Darsid identity in 2026.

 **Lone Yitoke** is the founder/owner of **Darsid Studio**
